# Little World

A play-and-talk web app for toddlers (about 1–4 years), hosted by Pip, a friendly character who listens.

Games: Talk with Pip, Copy me!, Peekaboo, Who's hiding?, My Words, Counting, Paint, Bubbles, Animals, and a birthday mode.

**Privacy:** every photo, recording and name a family adds is stored only in that device's browser. Nothing is uploaded.

To set it up for a child, open the app and hold the 🔒 in the top corner for 3 seconds to reach the grown-up corner.
Works on phones, tablets and laptops; use "Add to Home Screen" to install it.
